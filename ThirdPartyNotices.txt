Third Party Notices
===================

RustDesk 1.5.3 (Windows x64)
----------------------------
The unmodified RustDesk 1.5.3 Windows x64 client is embedded as a separate
program and extracted to the current user's LocalAppData directory when remote
control is approved. RustDesk is licensed under GNU AGPL version 3. The full
license text and the 1.5.3 corresponding-source package (including its pinned
hbb_common submodule) are embedded in the application and can be exported from
the Help window. Official project:
https://github.com/rustdesk/rustdesk/tree/1.5.3
Official release binary:
https://github.com/rustdesk/rustdesk/releases/download/1.5.3/rustdesk-1.5.3-x86_64.exe

FFmpeg
------
LanChat no longer bundles FFmpeg. Screen capture, video encoding and input
injection are handled entirely by the bundled RustDesk client.

Google Sans Flex (font)
-----------------------
Google Sans Flex is bundled as an embedded font resource and used as the UI
font (Latin glyphs), with Microsoft YaHei UI as the CJK fallback. The font is
distributed by Google via Google Fonts under the SIL Open Font License 1.1.
License: https://scripts.sil.org/OFL
Source: https://fonts.google.com/specimen/Google+Sans+Flex

Google Noto Emoji (emoji artwork)
---------------------------------
The built-in emoji picker uses 64 px Google/Noto emoji images, downscaled to a
32 px sprite sheet and embedded in the application. Noto Emoji is licensed
under the Apache License 2.0 (and CC-BY 4.0 for the artwork).
Source: https://github.com/googlefonts/noto-emoji
